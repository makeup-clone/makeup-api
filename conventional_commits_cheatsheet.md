# Conventional Commits Cheatsheet

| Префікс | Коли використовувати | Приклад |
| :--- | :--- | :--- |
| `feat:` | Додавання нового функціоналу | `feat: add header navigation menu` |
| `fix:` | Виправлення багу / помилки | `fix: resolve image alignment bug on mobile` |
| `style:` | Зміни у стилях (CSS/SCSS, відступи, форматування) | `style: update primary brand color in header` |
| `refactor:` | Переписання коду без зміни його поведінки | `refactor: simplify product filtering function` |
| `docs:` | Зміни в документації (`README.md`, коментарі) | `docs: add installation steps to README` |
| `chore:` | Технічні завдання (оновлення бібліотек, налаштування конфігів) | `chore: update vite dependencies` |
